# 🌸 Purple Bloom

**Purple Bloom** es una plataforma **SaaS** para **marcas de moda femenina**, que integra **diseño**, **catálogo** y **experiencia de compra** en un solo lugar.  
Pensada exclusivamente para ropa de mujer, combina **elegancia y simplicidad** para potenciar las ventas online.

---

## 📂 Estructura del proyecto
- `css/styles.css` → Estilos principales de la página.  
- `img/` → Imágenes del catálogo (`blusa-lavanda.jpg`, `hero-novedades.jpg`, `ofertas.jpg`, `pantalon-berenjena.jpg`, `tendencias.jpg`, `vestido-violeta.jpg`).  
- `js/` → Código JavaScript compilado desde TypeScript (`contact-form.js`, `nav.js`, `theme.js`).  
- `ts/` → Archivos fuente en TypeScript.  
- `index.html`, `catalogo.html`, `iniciar-sesion.html` → Páginas principales del sitio.  
- `package.json` / `package-lock.json` → Dependencias y scripts de compilación.  
- `node_modules/` → Librerías instaladas con npm.  
- `robots.txt` → Configuración para buscadores.  
- `sitemap.xml` → Mapa del sitio para SEO.  
- `tsconfig.json` → Configuración de compilación de TypeScript.  
- `README.md` → Documentación del proyecto.
